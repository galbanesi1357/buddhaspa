Ajustes

A chave da API do Claude fica salva só neste aparelho e é enviada direto para a Anthropic.

Crie em console.anthropic.com → API Keys. Use uma chave com limite de gastos.
As vozes vêm do próprio celular. Para vozes bem mais naturais: no iPhone, Ajustes → Acessibilidade → Conteúdo Falado → Vozes → Português (Brasil) e baixe uma voz "Aprimorada" ou "Premium" (ex.: Luciana ou Felipe). No Android, instale "Serviços de fala do Google" e, em Configurações → Conversão de texto em voz, baixe o português (Brasil). Depois volte aqui e escolha a voz.
Com uma chave da OpenAI, as falas usam uma voz neural com sotaque brasileiro (cerca de US$ 1 por hora de fala, cobrado pela OpenAI). Crie em platform.openai.com → API keys.
Tudo fica guardado só neste celular. Cada clipe ocupa cerca de 0,6 MB.
A velocidade da fala fica no botão 1x / 1,25x / 1,5x / 2x da barra de baixo. Você também pode pedir no chat: "fala mais rápido", "quero as direções".
No modo contínuo o Claude é consultado a cada 10 segundos (6 vezes por minuto).
